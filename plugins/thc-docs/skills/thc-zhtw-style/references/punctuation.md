# 【四、標點符號：字元級對照表】

本節依據為「團隊輸入慣例」(以台灣注音輸入法使用者的自然輸入為基準)；教育部《重訂標點符號手冊》僅為參考，與本表衝突時一律以本表為準。

【重要】提及豁免：本章表格與反例中「被展示」的字元本身不受規則約束；所有被提及的禁用字元與錯誤示例一律以反引號標記，讓自動化檢查工具可跳過 code span，避免誤報。

## 逐字元規則

| 字元 | 形制 | 規則 |
| --- | --- | --- |
| `，` | 全形 | 中文句內停頓。 |
| `。` | 全形 | 中文句尾。 |
| `、` | 全形 | 並列。只要該段落以中文為主，並列一律用頓號，含識別字並列。例：`gpt-oss-120b`、`nova2-bedrock`。 |
| `；` | 全形 | 中文分句。 |
| `：` | 全形 | 冒號前一個字元是中文字時。例：驗收：、要點：、原因： |
| `:` | 半形 | 冒號前一個字元「不是中文字」時 (英文、數字、反引號、半形右括號、半形引號均屬之)，冒號後加一個半形空格。例：`STATUS: Up`、實測 LiteLLM 版本為 `1.93.0`: 詳見附錄。 |
| `?` `!` | 半形 | 問號與驚嘆號一律半形 (含中文句尾)。後方接中文時加一個半形空格；後方接半形右括號、引號或位於行尾時不加空格。例：完成了嗎? 接著執行下一步。 |
| `「」『』` | 全形 | 中文語句的引用與強調 (巢狀用『』)。例：「遮罩加還原成功」。 |
| `《》` | 全形 | 書籍、手冊、標準文件的名稱。例：《重訂標點符號手冊》。 |
| `" "` | 半形 | 英文字串、指令輸出、原文引用。例：輸出 "Hello from Docker!"。 |
| `( )` | 半形 | 夾注一律半形。左右括號必須同一形制，不可一半形一全形。括號外側與中文或英文之間各留一個半形空格；外側緊鄰全形標點或位於行首、行尾時不加空格；識別字內部的括號依【三】逐字保留，不套用本條。 |
| `【】` | 全形 | 僅用於行內標籤，規則見本章「行內標籤」區塊。 |
| `%` `@` `#` `$` | 半形 | 一律半形。 |

## 禁用符號與替代寫法

原則：注音輸入法無法直接輸入的特殊符號、複合 Unicode 符號與裝飾符號，一律改用 ASCII 組合或中文改寫，提升可輸入性、可搜尋性與手寫感。程式碼區塊與引用的原文輸出不在此限 (依【三】逐字保留)。

| 禁用符號 | 改用 | 例 |
| --- | --- | --- |
| `≥` `≧` | `>=` 或「以上」 | 「50 GB 以上」；技術條件式寫 `>= 50`。 |
| `≤` `≦` | `<=` 或「以下」 | 「10 ms 以下」；技術條件式寫 `<= 10`。 |
| `≠` | `!=` 或「不等於」 | 回傳值不等於 0 時中止。 |
| `→` `←` `⇒` | `->` 或中文「改為」「至」「對應」 | 流程寫「A 至 B」；對照寫「server 對應伺服器」；技術語境寫 `A -> B`。 |
| `×` `÷` | `x` 或 `*`、`/` | 4 x 8 GB、`rate * 0.8`。 |
| `±` | `+/-` 或「正負」 | 誤差正負 5%。 |
| `≈` `≒` | 「約」 | 延遲約 100 ms。 |
| `—` `——` `–` | 改寫為冒號或逗號分句；確需連接符時用半形 `-` | 破折號的解釋語氣改寫為冒號或逗號分句。 |
| `…` | 半形 `...` | 接於行尾或範例省略處。 |
| `～` `~` (表範圍) | 「至」 | 「30 至 60」，不寫 `30~60`。 |
| `✓` `✗` `✔` `✘` | 「是」「否」或 O、X | 表格判定欄寫「是」「否」。 |
| `↑` `↓` | 「上升」「下降」或「增」「減」 | 流量上升 20%。 |
| `•` `‧` `・` | Markdown 清單符號 `-` 或頓號 | 清單一律用 Markdown 語法。 |
| `※` | 【注意】標籤或 blockquote | 兩者擇一，不疊用。 |
| `★` `☆` `■` `▲` 等裝飾符號 | 禁用，無替代 | 醒目需求改用【】標籤或粗體。 |
| `╔` `═` `║` `│` 等框線字元 | Markdown 標題與表格 | 僅「架構圖」且置於程式碼區塊內時可用。 |
| `＞` `＜` `＝` `＋` 等全形運算符 | 對應的半形字元 | 依【三】，識別字內尤其禁止全形。 |
| `①` `⑴` 等圈號 | 半形數字編號 `1.` `2.` | 清單一律用 Markdown 語法。 |

補充：半形 `>` 與 `<` 保留給技術語境 (比較條件、重新導向、泛型)；中文行文中不作「優先於」「大於」使用，改以文字表達。例：寫「優先順序由高至低依序為【三】、【四】」，不寫 `【三】 > 【四】`。

## 防滲漏規則 (重要)

半形僅限「括號、引號字元本身」與其「內部」的英文內容。括號或引號「外側」銜接的中文逗號、句號、頓號、分號，一律維持全形，不因緊鄰半形符號而改為半形。

- 正例：Presidio 純 regex recognizer (辨識器)，不安裝中文 NLP 模型。
- 反例 (禁止): `recognizer (辨識器),不安裝`、`grep 結果為 2;analyze 回傳`。反例中的半形逗號與分號皆為錯誤，應為全形的 `，` 與 `；`。

## 中英文間距

中文字與英文單字、數字之間加一個半形空格。例：安裝 Docker 之後、容量為 20 TB。全形標點與任何字元之間不加空格。

## 斜線

技術數值與識別字之間用半形 `/` (如 `6006/4317`、4 vCPU / 8 GB)；中文詞並列不用斜線，改用頓號或「與」「或」。

## 行內標籤

1. 【】僅用於「行內標籤」：醒目的短標記，置於句首、表格儲存格開頭或清單項開頭，不插入句中。只可使用以下標籤詞，不得自創：【注意】【重要】【必要】【實測】【暫譯】【待辦】【正式環境】。
2. 位置例外：【暫譯】置於暫譯詞之後，不受句首限定約束。例：保留 attestation 並附暫譯「認證聲明」【暫譯】。
3. 密度規則：每句至多一個標籤；所在區塊的標題已表達同一語意時，不逐項重複該標籤 (例：標題已是「待辦」的清單，項目不再逐條加【待辦】)。整段警示仍用 Markdown blockquote 加粗體，兩者擇一，不疊用。
4. 編號豁免：本指南自身的章節標題【一】至【七】與章節交叉引用 (如「依【三】處理」) 不受標籤白名單限制；一般文件的章節引用寫「第 N 章」「第 N 節」，不使用【】。

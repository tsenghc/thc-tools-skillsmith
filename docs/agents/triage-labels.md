# Triage 標籤

技能以五個標準 triage 角色描述 issue 的狀態。本檔將這些角色對應到本儲存庫實際使用的標籤字串。

| mattpocock/skills 的標籤 | 本儲存庫的標籤 | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待維護者評估 |
| `needs-info` | `needs-info` | 等待回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交由無人值守的 agent 執行 |
| `ready-for-human` | `ready-for-human` | 需要由人實作 |
| `wontfix` | `wontfix` | 不予處理 |

技能提到某個角色時，例如「套用 AFK-ready 的 triage 標籤」，使用上表對應的標籤字串。本儲存庫採本機 Markdown，標籤寫在 issue 檔的 `Status:` 行。

如需改用其他名稱，直接修改「本儲存庫的標籤」欄位。

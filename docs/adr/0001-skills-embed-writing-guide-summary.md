# 技能內附風格規範摘要，而非相依於 thc-zhtw-style

`thc-gitcommit`、`thc-handoff`、`thc-onboarding` 各自是獨立的 plugin，安裝時無法保證 `thc-zhtw-style` 也已安裝，因此每個技能內附一份風格規範的精簡摘要，即內建寫作規範；環境中已安裝 `thc-zhtw-style` 時，改以其完整規則為準。代價是摘要必須手動與風格規範同步：修改風格規範時，必須一併檢查三個技能的內建寫作規範。

## 考慮過的方案

| 方案 | 結論 | 原因 |
| --- | --- | --- |
| 技能直接相依於 `thc-zhtw-style` | 否決 | 未安裝 `thc-docs` 的裝置上，技能會失去寫作規則，產出的寫法不一致 |
| 把三個技能併入 `thc-docs` | 否決 | 安裝單位變大，違反「每個技能可單獨安裝」的發佈方式 |
| 各技能內附摘要 | 採用 | 每個 plugin 自成一體；同步成本只在修改風格規範時發生，且頻率低 |
